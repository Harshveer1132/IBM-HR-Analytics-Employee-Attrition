# IBM HR Analytics — Employee Attrition

## Overview

Exploratory Data Analysis of the IBM HR Analytics Employee Attrition dataset using Python.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Analysis

The project analyzes:

* Employee demographics
* Department and job roles
* Attrition patterns
* Overtime
* Age and tenure
* Job satisfaction
* Work-life balance
* Monthly income
* Correlations between HR variables

## Key Findings

* Overall attrition rate: **16.1%**
* Younger employees showed higher attrition.
* Short-tenure employees showed higher attrition.
* Overtime employees showed substantially higher attrition.
* Attrition varied considerably across job roles.
* Lower income and lower employee-experience indicators were associated with higher attrition.

## Files

* `notebooks/` — Complete Python EDA notebook
* `visuals/` — Key analysis visualizations
* `data/` — Dataset

## Project Goal

Identify employee groups and workplace factors associated with attrition and provide data-driven HR insights.
